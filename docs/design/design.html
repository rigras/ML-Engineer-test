2 · Extract flow POST /api/extract — what makes a box trustworthy

Locating names by character offsets instead of searching the text gives one box per real occurrence, handles repeated names and never guesses. Matching is max(ratio, token_sort_ratio) on casefolded, accent-stripped names, so María González ~ Maria Gonzalez and word order is tolerated, with no substring inflation.

The README's sample stack (thefuzz) is replaced by rapidfuzz, which thefuzz now wraps. Pages are 0-based; coordinates rounded to 0.01 pt; a bottom-left consumer flips y' = page_height − y − height.

4 · Ask sequence POST /api/ask — the LLM writes text; code decides everything else

Ingest. Same OCR → OCR layout blocks packed into ≤ 250-token, page-bounded chunks; a unit that does not fit moves whole to the next chunk, so no word is ever cut and nothing passes e5's 512-token window. IDs are sha256(pdf)[:16]:chunk: a second document can't overwrite the first and re-ingesting is an idempotent upsert.

Why hybrid + rerank. Dense search misses exact names and figures; BM25 catches them. e5 similarities sit in a narrow 0.7–1.0 band, useless for "not found"; the reranker's score separates relevant from irrelevant, so it powers the gate (calibrated on the golden questions).

6 · Scaling to 1000+ PDFs/hour

1000 PDFs/h = 0.28 PDF/s. OCR dominates at ~2–3 CPU-s per page: a 5-page average keeps ~4 cores busy, ~8 with headroom. The CPU work leaves the request path; the same image becomes the worker.

8 · Routing between models by query complexity

AnswerGenerator is a port, so a router is one more adapter — no use case changes. A deterministic router scores the question after retrieval:

  • passages above the gate (1 → lookup, several → synthesis);
  • cues for comparison, aggregation or "why";
  • question length and language.

Simple lookup → small fast model (gpt-oss-20b).
Multi-passage / reasoning → large model (gpt-oss-120b).
Escalation: if the small model returns no valid citation while the gate found evidence, retry once on the large model.

Thresholds are tuned on the golden Q&A set (pass^3 and cost per answer), never decided by the LLM itself.
